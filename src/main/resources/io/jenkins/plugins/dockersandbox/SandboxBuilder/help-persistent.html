Name (1-40 letters, digits, _ or -) of a long-lived sandbox that is reused by later builds. Empty means a normal one-shot sandbox. The first build creates the sandbox (display name jkp-<name>); later builds find it, start it if it is stopped and run in it again, with files and installed tools intact. Builds that use the same name run one after the other. Image, kit and size only apply when the sandbox is created.
